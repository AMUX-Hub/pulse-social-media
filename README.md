# AMUX Pulse · social media images

Public host for finished AMUX Pulse post images. Instagram's publishing API downloads media by
URL, so every image here has a stable public address:

    https://raw.githubusercontent.com/AMUX-Hub/pulse-social-media/main/<week>/<id>.jpg

Only finished, approved post images go here. No app screenshots, tester data or drafts: everything
in this repo, including its history, is public.

| Folder | Week | Contents |
| --- | --- | --- |
| `w1/` | 12–17 Oct 2026 | P-01, P-02 carousels; P-03, P-04 Reel cards; TikTok `tt1`; highlight covers `hl-*` |
| `w2/` | 19–25 Oct 2026 | P-05, P-06 carousels; R-02, R-03 Reel cards; TikTok `tt4`; Story cards `s2-*` |
| `x1/` | 10–16 Oct 2026 | Value series 1: V-01…V-13 (myth-busts, rule cards), Reel V-04, Story questions `q-*` |

Reels: `<week>/reels/reel-<id>.mp4`, 1080×1920 H.264 card cuts.

Ids: `pNN-k` feed posts (slide k), `rNN-k` Reel cards, `ttN-k` TikTok slideshow, `sN-*` Stories,
`hl-*` highlight covers. JPEG, 1080×1350 (feed) or 1080×1920 (Reels, Stories, TikTok).

Source, captions and alt text live in the app repo (`docs/marketing/social/`).
